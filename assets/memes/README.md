# Memes do ganso 🖼️

Coloque aqui as imagens que você quer que o ganso traga pra tela de vez em
quando (como no Desktop Goose original). O ganso abre uma delas, em posição
aleatória, quando está no clima de bagunça.

- Formatos aceitos: `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`
- Pode colocar quantas quiser — ele sorteia uma por vez.
- Se a pasta estiver vazia, o ganso simplesmente não abre memes.

> Nada vem aqui por padrão de propósito: as imagens do app original têm
> direitos autorais, então use as suas próprias (ou memes livres).

Ajuste a frequência em `config.json` (`chanceMeme`) ou desligue com
`"memes": false`.
